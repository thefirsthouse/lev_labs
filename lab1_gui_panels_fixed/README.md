# GUI лабораторной №1 — вариант 3

Это компактный desktop-интерфейс для предоставленного симулятора.

Главное правило Timeline:

**строка = аппаратный ресурс, а не команда.**

Фиксированные дорожки:

- КОНВЕЙЕР 1
- КОНВЕЙЕР 2
- КЭШ
- КЭШ-КОНТРОЛЛЕР
- СШ
- БЭ
- ОП
- УСО

Одна команда может иметь несколько событий на разных ресурсах; `command_id` только связывает эти события.

## Вариант 3

- МДО: 30
- МСО: 40
- Управление объектом: 30
- Диспетчеризация: 10–70
- Кэш: 65% / 85%
- ОП: 4-1-1-1
- СШ: 266 МГц
- МП: 700 МГц
- 2 конвейера
- FIFO для СШ

## Запуск

```bash
cd lab1_gui_compact_final
python3 app.py
```

Ubuntu/Debian при необходимости:

```bash
sudo apt install python3-tk
```

## Управление

`▶` — автоматическое выполнение по одному такту.

`Ⅱ` — пауза.

`⏭` — ровно один такт.

`↺` — новая симуляция.

`− / +`, 100%, 200% и Ctrl+колесо — масштаб Timeline.

Ползунок `ТОЛЩИНА` увеличивает/уменьшает высоту дорожек и блоков.
