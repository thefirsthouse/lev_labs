# Fix

Исправлена только причина остановки GUI после нескольких тактов.

В `app.py` Timeline обращался к `e.duration`, но в компактной версии `Event` не имел свойства `duration`. На первом событии, для которого отрисовывался 4-1-1-1, возникал `AttributeError` внутри Tkinter callback `auto_step`. После исключения callback больше не планировал следующий шаг, поэтому казалось, что симуляция остановилась на 2–3 такте.

Исправление: добавлено свойство `Event.duration = end - start`.

Кнопки, размеры панелей и остальной интерфейс не менялись.
