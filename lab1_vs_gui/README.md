# GUI для лабораторной №1, вариант 3

Локальное desktop-приложение на Python/Tkinter, построенное поверх предоставленной модели симулятора.

Главный принцип визуализации:

- строка Timeline = **аппаратный ресурс**;
- прямоугольник = **реальная операция использования ресурса**;
- `command_id` связывает события одной команды, но **не создаёт отдельную строку**;
- СШ, БЭ, ОП и УСО отображаются только в тех интервалах, когда реально заняты;
- КЭШ не остаётся подсвеченным после завершения конкретного обращения;
- для одной команды можно увидеть последовательность событий на разных дорожках.

## Запуск

```bash
cd lab1_vs_gui
python3 app.py
```

Если `tkinter` отсутствует в Ubuntu/Debian:

```bash
sudo apt install python3-tk
```

## Что реализовано

- два конвейера;
- МДО, МСО, Управление объектом и Диспетчеризация;
- вариант 3 с исходными распределениями;
- Cache 65% / 85%;
- FIFO для СШ;
- ОП 4-1-1-1;
- СШ 266 МГц и МП 700 МГц;
- реальный пошаговый режим;
- автозапуск;
- zoom и прокрутка Timeline;
- кликабельные события и подсказки;
- состояние МП, КЭШ, СШ, БЭ, ОП, УСО;
- трасса `ResourceEvent` непосредственно из Simulation Engine.

## Архитектура

```text
Simulation Engine
      |
      +-- Pipeline 1
      +-- Pipeline 2
      +-- Cache
      +-- Cache Controller
      +-- FIFO Bus
      +-- Buffer Element
      +-- Memory
      +-- USO
      |
      v
 ResourceEvent[]
      |
      v
 Timeline Renderer
```
